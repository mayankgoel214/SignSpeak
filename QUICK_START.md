# SignSpeak AI - Quick Start Guide

## 🚀 Get Running in 3 Steps

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Run the App
```bash
python app.py
```
Or on Windows, double-click `run.bat`

### Step 3: Open Browser
Navigate to: **http://localhost:7860**

- ✅ Real-time sign language detection

## 💡 Usage Tips

1. **Good Lighting** - Ensure your hand is well-lit
2. **Plain Background** - Use a simple background for better detection
3. **Hold Gesture** - Keep gesture steady for 1.5 seconds
4. **Distance** - Position hand 1-2 feet from camera
5. **Full Visibility** - Keep entire hand in frame

## ❓ Troubleshooting

**Camera not working?**
- Check browser permissions
- Refresh the page

**Hand not detected?**
- Improve lighting
- Use plain background

**Low accuracy?**
- Train custom model with your data
- Ensure proper hand positioning
